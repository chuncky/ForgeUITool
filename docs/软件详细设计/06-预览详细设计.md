## 6.2 SdlBackend 流程（对标 Beken / UIBuilder）

```text
1. validate(projectRoot) 失败则中止
2. generate(projectRoot)
3. 将 templates/sdl-sim 同步到 .forge/preview-build/（或增量）
4. 把 `<codegenDir>/`（含 `custom/`）经 `forgeui_generated.cmake` 链进预览 CMake
5. 配置 LV_COLOR_DEPTH / 分辨率与 project.display 一致
6. cmake --build **--parallel**（**异步 spawn**；**禁止**每次 wipe `out/`；指纹变时 soft-clean CMakeCache）&& 启动 SDL 进程（detached）
7. 优先预编译 SDL2 + MinGW/ccache（`xos-package/tools/win`；可用 `npm run sync:xos-tools` 从 Beken 参考树同步）；Release 预览配置（FR-061b）
8. 设计器/CLI 订阅 stdout/stderr；失败展示编译日志（FR-061）
9. 编译进行中：previewStore.busy=true，画布 pointer-events:none（FR-061a）
```

**非阻塞约束（FR-061a，根因说明）：**

| 反模式 | 现象 | 正确做法 |
|--------|------|----------|
| Electron Main 上 `spawnSync(cmake …)` | Windows 下整窗「未响应」；画布拖放/选中 IPC 排队 | `runProcessAsync` + 事件循环继续处理 IPC |
| 构建日志逐行 push 到 reactive 数组 | 日志面板重绘拖慢 Renderer | 单次 append 合并 stdout/stderr，超长截断 |
| 编译期间仍允许画布写操作 | mouseup 触发 `updateNode` IPC 与 cmake 串行 | `previewStore.busy` 锁画布；App 底栏 `.foot` 显示 phase |

对标 Beken：`ref/beken` 分析 — 「spawn 工作 2/3 的命令，日志进面板」，主 UI 线程不跑同步编译。

**模板要求：** 使用产品 LVGL（`xos-package/lvgl` → release `third_party/lvgl`）；禁止依赖他厂闭源 sim。**禁止**把 Beken/上游完整 LVGL 混进 release（会多出 `al88/l8/…` 且 typedef 与 QM 的 `_lv_draw_sw_blend_*` 不一致，MSVC 编译失败且源文件暴增变慢）。

**PC 预览与 xos LVGL 兼容（必守）：**

| 点 | 做法 |
|----|------|
| `lv_conf.h` | 同步到 `.forge/preview-build/`；`CMakeLists.txt` 对 **lvgl 目标** `target_include_directories(... PUBLIC preview-build)` + `LV_CONF_INCLUDE_SIMPLE`，否则清理后重编 LVGL 会 C1083 |
| `lv_drv_conf.h` | PC 预览提供 stub（xos 设备头由 `XOS_INTERFACE_INC` 提供）；`LV_USE_OBJ_ID_BUILTIN` 须与 `LV_USE_OBJ_ID` 一致 |
| `BUILD_SIMULATOR=1` | 注入 lvgl 编译定义，跳过设备侧 `qua_mm_system` 等 |
| 源裁剪 | `optimize_drivers.cmake` 排除 GPU/SoC、非 SDL 驱动、xos 设备源，以及产品树不存在的 orphan blend（al88/l8/i1/…） |
| 色深格式 | PC 预览只开 xos 已实现的 SW blend：`RGB565` / `RGB888` / `ARGB8888`（关 AL88/L8/I1 等） |
| ThorVG | PC 预览关闭 `LV_USE_VECTOR_GRAPHIC` / `LV_USE_THORVG_INTERNAL` |
| SDL zoom | 产品树 SDL 驱动须用 **float zoom**（与 Beken/`hal.c` 一致）；`uint8_t` 会把 0.7 截成 0 → 窗口/除零/卡死 |
| 色格式 | `lv_sdl_window_create` 后设 `LV_COLOR_FORMAT_NATIVE`（勿用默认 `NATIVE_WITH_ALPHA`/RGB565A8，否则 fb 偏小 assert） |
| 工具链 | 优先 `xos-package/tools/win`（w64devkit + cmake + sdl2）+ Ninja/ccache；打包进 `forgeui-root`；避免默认 MSVC。可用 `FORGEUI_PREVIEW_GENERATOR` 强制 |
| 缓存 | configure 指纹含 `lvglStamp`；仅当 LVGL 树变化时 wipe `lvgl_build`，保留 SDL 对象；UI 增量不重编 LVGL |
| 回归 | `pipeline_validate_generate_preview`：`buildOnly` + **wipe `out/` 后再编**（防增量缓存掩盖） |

## 6.3 WasmBackend（stub → V2，对照 EEZ / LVGL Pro）

**目录：** `packages/preview-host/backends/wasm/`

| 组件 | 职责 |
|------|------|
| `lvgl-emscripten/` | LVGL 9.10 源码 + 平台 stub（display/indev 桥） |
| `forge-bridge.ts` | IR 或 generated 符号 → Wasm 侧建对象树（与 SDL 消费同源 IR） |
| `runtime.worker.ts` | Worker 内 `_mainLoop`；帧缓冲 → OffscreenCanvas / ImageData |

**与 EEZ 差异（合规）：** 不引用 `lvgl_runtime_v*.js`；不链 eez-flow；GPL 仓仅作 **架构阅读**，代码自研。

**接口演进：**

```ts
// V2 目标签名（MVP 仍 throw E_PREVIEW_WASM_NOT_IMPL）
interface WasmPreviewSession extends PreviewSession {
  canvas: OffscreenCanvas | HTMLCanvasElement;
  postMessage(event: PreviewInputEvent): void;  // 点击/触摸注入 indev
}
```

**验收（AC-008）：** 同一 golden 工程，SDL 与 Wasm 对象树深度/screen 列表一致（像素 diff 可选 P2）。
