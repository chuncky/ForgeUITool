# 单目录生成物设计方案（对标 Beken `beken_generated`）

> **版本：** V1.0  
> **日期：** 2026-07-30  
> **状态：** 已锁定（D-07）  
> **依据：** `docs/生成代码问题/bk生成代码结构.png`；Beken 实际产物 `beken_generated/` + 内置 `custom/`  
> **上游：** 《设计需求文档》《软件概要设计说明》《软件详细设计说明》

---

## 1. 问题与目标

### 1.1 现状（待废弃）

工程根下 **并列** 两个目录：

```text
<projectRoot>/
  generated/     # 工具生成，再生成可覆盖
  user/          # 用户业务，再生成不覆盖
```

导出 SDK 时需 **拷贝两个目录** 并在 CMake 中分别收录，与 Beken / 多数 LVGL SDK 集成习惯不一致。

### 1.2 Beken 参照（`bk生成代码结构.png`）

**全部生成物位于同一目录** `beken_generated/`：

```text
beken_generated/
  beken_generated.cmake    # SDK 一行 include 收录全部 .c
  beken_ui.c / beken_ui.h
  event_runtime.c / .h
  basic_callback.c
  Page_1_init.c            # 按页初始化源文件
  image/                   # 生成后的图片资源
  fonts/                   # 生成后的字体资源
  custom/                  # 用户可改；再生成不覆盖
```

SDK 集成典型写法：

```cmake
include("${FORGEUI_GENERATED_DIR}/forgeui_generated.cmake")
# 或 Beken: include("${BEKEN_GENERATED_DIR}/beken_generated.cmake")
```

### 1.3 目标

| 目标 | 说明 |
|------|------|
| **单目录拷贝** | 「导出到 SDK」整目录复制一次即可 |
| **单 CMake 入口** | 根目录提供 `forgeui_generated.cmake`，递归收录 `.c` / 头文件 include 路径 |
| **隔离语义不变** | 工具生成区可覆盖；`custom/` 内文件再生成 **永不覆盖**（延续 D-02 心智，目录名对齐 Beken `custom/`） |
| **设计器/CLI 一致** | CodeGen、预览 CMake、代码编辑器、清理策略共用同一目录契约 |

| ID | 结论 |

## 3. 目录布局（权威）

### 3.1 工程根

```text
<projectRoot>/
  project.json
  screens/
  assets/                      # 设计期资源（源图、TTF 等）
    images/
    fonts/
  forgeui_generated/           # A1 单目录输出（默认名；对标 beken_generated）
    forgeui_generated.cmake    # SDK / 预览统一 include
    ui.h
    ui.c                       # ui_init / ui_deinit
    ui_nav.c / ui_nav.h        # V1 切屏辅助
    screens/                   # 按屏拆分（本产品保留 screens/ 子目录，非 Beken 扁平 Page_*）
      screen_home.c
      screen_home.h
      ...
    image/                     # 生成后的图片 C/bin（对标 bk image/）
    fonts/                     # 生成后的字体 C/bin（对标 bk fonts/）
    custom/                    # 用户区；再生成不覆盖
      ui_events.h
      ui_events.c
      custom_func.h            # V1 可选；对标 bk custom_func
      custom_func.c
  packages/                    # A2
  .forge/
    build-manifest.json        # 清单路径前缀为 forgeui_generated/
    preview-build/
```

### 3.2 读写边界

| 路径 | 写入者 | 再生成行为 | 设计器代码编辑器 |
|------|--------|------------|------------------|
| `forgeui_generated/**`（**不含** `custom/`） | CodeGen | **覆盖** | 只读 |
| `forgeui_generated/custom/**` | CodeGen（仅首次）+ 用户 | **不覆盖**已有文件；新 handler 可文末追加 | 可编辑 |
| `assets/**` | 设计器 / 用户 | 与生成无关 | — |
| `screens/**`、`project.json` | 设计器 | 与生成无关 | — |

### 3.3 `forgeui_generated.cmake` 契约

对标 `ref/beken/.../beken_generated.cmake`：

- 以 **cmake 文件所在目录** 为根；
- `GLOB_RECURSE` 收集根下及子目录全部 `.c`（**含** `custom/*.c`）；
- 收集 `.h` 所在目录为 include 路径（含 `screens/`、`custom/` 等子目录）。

预览模板 `templates/sdl-sim/CMakeLists.txt` 与 SDK 导出说明均改为：

```cmake
include("${FORGEUI_GENERATED_DIR}/forgeui_generated.cmake")
target_sources(app PRIVATE ${FORGEUI_GENERATOR_SOURCES})
target_include_directories(app PRIVATE ${FORGEUI_GENERATOR_INCLUDE_DIRS})
```

（宏名实现期可与 Beken 对齐为 `FORGEUI_GENERATOR_*`，文档统一用此前缀。）

## 4. `project.json` 字段

### 4.1 新字段

```json
"export": {
  "codegenDir": "forgeui_generated",
  "customSubdir": "custom",
  "imageMode": "c_array",
  "lvglInclude": "lvgl/lvgl.h",
  "packageDir": "packages/latest"
}
```

| 字段 | 默认 | 说明 |
|------|------|------|
| `codegenDir` | `forgeui_generated` | 单目录生成根；可改为 SDK 要求的相对名 |
| `customSubdir` | `custom` | 相对 `codegenDir`；**不得**指向 `codegenDir` 外 |

### 4.2 废弃字段（兼容读取，M2 迁移后移除）

| 旧字段 | 迁移 |
|--------|------|
| `export.generatedDir` | → `export.codegenDir` |
| `export.userDir` | → `export.customSubdir`（文件搬到 `<codegenDir>/custom/`） |

**迁移策略（实现期）：**

1. 若存在旧 `generated/` + `user/` 且无 `forgeui_generated/`：首次 `forgeui generate` 时合并搬迁并写回 `project.json`；
2. 若仅存在旧布局：CLI 打印一次性迁移提示；
3. 黄金用例 G-02～G-03 改用新路径。

## 5. CodeGen / 清理 / 导出

### 5.1 生成

- CodeGen 仅写入 `<codegenDir>/` 下非 `custom/` 区域 + 首次创建 `custom/` 桩；
- 模板路径：`packages/codegen/templates/c/custom/ui_events.*`（物理模板目录可仍叫 `custom/`，输出到 `<codegenDir>/custom/`）。

### 5.2 全部清理（FR-060d）

| 操作 | 范围 |
|------|------|
| 删除工具生成物 | `<codegenDir>/` 下 **除 `custom/` 外** 的全部文件与子目录（含 `screens/`、`image/`、`fonts/`、`*.cmake`） |
| **保留** | `<codegenDir>/custom/**` **永不删除** |
| 预览缓存 | `.forge/preview-build/out`（不变） |

### 5.3 导出到 SDK（FR-008）

| 旧行为 | 新行为 |
|--------|--------|
| 拷贝 `generated/` + `user/` 到 SDK `ui/` | **仅拷贝** `<codegenDir>/` **一整棵目录** 到 `sdk.copyTargetRel`（默认 `ui/forgeui_generated` 或整目录替换 `ui/`，由 PlatformPlugin 配置） |
| SDK 文档写两套路径 | SDK 文档：**复制目录 + include 一个 cmake** |

推荐 SDK 侧目录：

```text
<sdkProject>/ui/forgeui_generated/    # 与设计器工程内同名，便于对照
```

或扁平合并到 `<sdkProject>/ui/`（整目录内容拷贝到 `ui/` 根）——由 `PlatformPlugin.copyCodegenDir(mode)` 支持两种模式，**默认「整目录拷贝」**。

## 6. 设计器与 MCP

| 模块 | 变更 |
|------|------|
| **代码编辑器** | 可编辑：`{codegenDir}/{customSubdir}/**`；只读浏览：同 `codegenDir` 下其余文件；默认打开 `custom/ui_events.c` |
| **listCodeFiles IPC** | 扫描 `codegenDir`；`editable` 标志 = 路径位于 `customSubdir` 下 |
| **MCP AR-022** | 禁止写 `codegenDir` 非 `custom` 区域；禁止覆盖 `custom` 已有实现 |
