## UI-01 — 双页工程（AC-001）

## UI-02 — 拖拽 + 事件 + 存档（AC-002）

| # | 步骤 | 期望 | ☐ |
|---|------|------|---|
| 1 | 在 `home` 画布从 **控件库** 拖入 **按钮** | 画布出现新按钮 | |

| 4 | **Ctrl+S** 或顶栏 **存档** | 状态栏提示已保存 | |
| 5 | 检查 `screens/home.json` | `events[]` 含上述绑定 | |
| 6 | 顶栏 **C 语言 → 生成代码** | 成功；`user/ui_events.c` 未被覆盖（若曾手工编辑） | |

**通过标准：** 1～6 全部满足。

## UI-03 — SDL 模拟运行（AC-003）
