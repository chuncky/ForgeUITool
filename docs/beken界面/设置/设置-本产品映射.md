# 设置功能对齐 BK — 修正方案（V1.32）

> **依据：** `docs/beken界面/设置/设置1～4.png`、工作区项目设置图；Beken `workspace-ai-design.md`  
> **用户修订：** AI 设置与 BK 一致 —— **自动检测，无「启用 AI」开关**（取消 NFR-004 默认关的门控实现）

## 1. 双入口（不变）

| 入口 | 形态 | 作用域 |
|------|------|--------|
| 壳顶栏「设置」 | 整页左栏四分类 | 本机偏好 |
| 工作区「项目设置」 | 模态 Tab | `project.json` |

## 2. 全局设置四分类

### 2.1 通用设置
- 语言（与工作区 `uiLocale` **单源**）
- 主题：2～3 套 CSS 变量可切 + 网格 UI（其余 BK 预设可占位）
- 默认平台 / SDK 路径 / 默认预览后端（SDK 路径接到导出）

### 2.2 工作台设置
- 隐藏网格 → `canvasView.showGrid`
- 隐藏事件连线 → `showEventLinks`（先持久化，渲染可分期）
- 对齐线阈值 1–5 → `alignSnapPx`

### 2.3 快捷键设置
- 只读分组列表（与 `keyboard.ts` 对齐），不可改键

### 2.4 AI 设置（对齐 BK `设置4.png`：自动检测，无启用开关）

Beken 行为：打开「AI 设置」即展示：

1. **MCP服务状态**：运行中/未就绪/离线 + 刷新（Bridge `READY` 才算运行中）  
2. **AI 编辑器** 子 Tab：Cursor | Codex | TRAE | TRAE CN | 手动配置 MCP  
3. 每宿主：exe 路径 +「自定义」、MCP/Skill 状态（含安装版本 ok/outdated/missing）与路径、安装/更新 | 卸载 | 刷新  

**没有**「启用 AI 设计」勾选。

本产品应对齐为：

| 项 | 行为 |
|----|------|
| **无** `aiDesignEnabled` UI | 删除设置页/诊断页勾选 |
| Bridge | 有工程进工作台即 READY；设置页「MCP服务状态」仅 `READY`=运行中；刷新重 ping + 可见反馈（刷新中/已刷新/上次刷新） |
| 宿主检测 | 自动检测 Cursor/Codex/TRAE/TRAE CN；支持自定义 exe（`ai-tools.json`） |
| 宿主 MCP/Skill | 已装/需更新/未装 + **安装版本**（`appVersion` / Skill `manifest.json`）；操作「刷新」重读版本态 |
| 顶栏「AI设计」 | **仅**在无工程或 `previewBusy` 时禁用；**不再**因「未启用」灰显 |
| Bridge 写路径 | **移除** `AI_DISABLED` / `ai:setEnabled` 门控（或恒为允许） |
| 持久化 | 删除 `settings.aiDesignEnabled`；Main 侧不再依赖启用标志 |

说明：详设里的 NFR-004「显式授权」改为 **用户主动从「AI设计」启动并安装 MCP** 即视为授权（与 BK 一致），不再单独开关。详见 [`AI设计-本产品映射.md`](../AI设计/AI设计-本产品映射.md)。

## 3. 项目设置

- Tab：**基础** | **导出/交付**
- 基础含：名称、platform（可选）、分辨率、色深、lvgl、默认屏、**启用多语言**（工程级，≠ AI 开关）
- 导出：sdk.path、deliveryMode、previewBackend、交付按钮

## 4. 实现顺序

1. 文档：`设置-本产品映射.md`；修正 `AI设计-本产品映射.md`（去掉启用开关）
2. 去掉 `aiDesignEnabled` 全链路（settings / App sync / toolbar disabled / bridge / AiAssistDialog）
3. `SettingsView` 四分类壳；AI 分类内嵌检测面板
4. 工作台偏好接线；locale 单源；项目设置 Tab
5. 测试更新 + build

## 5. 验收（AI 相关）

1. 设置 → AI：无启用勾选；布局含 MCP 服务状态 + 编辑器子 Tab（对齐 `设置4.png`）  
2. 未开工程时顶栏 AI 灰；开工程且非预览忙则可点  
3. AI设计 → Cursor 可启动；MCP 可写画布（无需先勾选启用）  
4. 非默认安装路径的 Cursor 仍能检测为已安装（或可自定义 exe）
