## 与当前「大纲」差距

| 能力 | Beken | 当前 Outline | 目标 |
|------|-------|--------------|------|
| 面板标题 | 页面 + 组件树 | 单一「大纲」 | 两段式标题 + 计数 |
| 页面列表 | 纵向列表 + 火箭 + ⋯ | 横向 Tab + `+` ✎ − | 对标上图 |
| 复制页面 | 有 | 无 | FR-011b |
| 页面顺序/叠层 | 有 | 无 | FR-011b |
| 启动页 | 火箭图标 | 仅 `defaultScreen` 字段 | FR-011b UI |
| 组件树 / 控件树 | 当前页控件；眼睛 + ⋯ | 递归树；无行内操作 | FR-013a/b |
| ⋯ 菜单 | **悬浮于面板之上**（Teleport） | 列表内 absolute，被 overflow 裁剪 | **FloatingPanelMenu** |
| 锁定/隐藏 | 行内 + 菜单 | Schema 有字段；UI 未接 | FR-013a |
| 层级调整 | 菜单 + 拖拽 | 无 | FR-013b（MVP 菜单；V1 拖拽） |
| 对齐 | 菜单 6 向 | 仅拖拽吸附 | FR-013b（V1 多选） |
| 自定义控件 | 菜单入口 | FR-019 未挂树 | V1 |

## 数据与 Core API（待实现）

**页面：**

| API | 行为 |
|-----|------|
| `duplicateScreen(screenId, opts?)` | 深拷贝 screen JSON；新 id/file；插入 `project.screens` |
| `reorderScreen(screenId, where: up\|down\|top\|bottom)` | 调整 `project.screens` 数组顺序（**页面叠层/列表顺序**） |
| `setDefaultScreen(screenId)` | 写 `project.defaultScreen`；UI 火箭高亮 |

**控件（`parent.children[]` 顺序 = 绘制叠层，后者在上）：**

| API | 行为 |
|-----|------|
| `duplicateNode(screenId, nodeId)` | 同级复制；新 id；偏移 frame |
| `moveNodeOrder(screenId, nodeId, where)` | 同级 up/down/top/bottom |
| `moveNode(...)` | 已有详设 §4.1.3；变更父级或 index（V1 拖拽） |
| `setNodeFlags(screenId, nodeId, { locked?, hidden? })` | 写 `Node.locked` / `Node.hidden` |
| `alignNodes(screenId, nodeIds, mode)` | 相对父容器或 screen 边界对齐（V1；需多选） |

**IPC 建议：** `project:duplicateScreen`、`project:reorderScreen`、`project:setDefaultScreen`、`project:duplicateNode`、`project:moveNodeOrder`、`project:setNodeFlags`、`project:alignNodes`。

## 画布联动

| 状态 | 画布 | 控件树 |
|------|------|--------|
| `hidden: true` | 不绘制；可选虚线框 | 眼睛关闭图标；名称灰显 |
| `locked: true` | 可选中但不可拖/缩；或禁止选中（MVP：禁止拖缩） | 锁图标 |
| 选中 | 高亮框 | 行背景 + 左边条（对标 Beken 蓝条） |
