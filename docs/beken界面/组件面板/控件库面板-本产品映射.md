# 控件库面板 — Beken 参照与本产品映射

> **Beken 参照图：** `组件面板.png`  
> **Beken 原文：** `界面说明.txt` §2.3「组件库：组件库面板开关」  
> **本产品术语：** 统一称 **「控件库」**（toolbar 按钮文案亦为「控件库」）

## 顶栏按钮

| Beken | 本产品 | 行为 |
|-------|--------|------|
| 组件库 | **控件库** | 仅切换左侧 **WidgetLibraryPanel** 显示/隐藏；不影响大纲、属性、事件面板 |

## 面板结构对照

| Beken 组件面板 | 本产品 WidgetLibraryPanel |
|----------------|---------------------------|
| 标题「组件库」 | 标题「控件库」 |
| Tab：系统组件 | Tab：**系统控件** |
| Tab：自定义组件 | Tab：**自定义控件** |
| 搜索「搜索组件…」 | 搜索「搜索控件…」 |
| 分类折叠 + 数量 + 磁贴 | 同左；分类 id 见详设 §9.7.1 |
