# 资源管理 — Beken 对照与本产品映射

> **日期：** 2026-08-06  
> **Beken：** `workspace-toolbar.md` §5.4、`workspace-i18n.md`  
> **实现：** `AssetsDialog.vue`（主 Tab：图片 | 字体 | 多语言）

## 对照表

| 概念 | Beken | Forge |
|------|-------|-------|
| 入口 | 顶栏「资源管理」 | 同左 `tb.assets` |
| 图片 | 添加 PNG → 选中 → 删除 | 添加（多格式兼容）+ 缩略图 + 引用数 + 删除 |
| 字体 | 添加 TTF → 删除 | 同左 + 引用数 |
| 多语言 | **资源管理内「多语言」Tab** | **并入**同一对话框；顶栏无独立「多语言」按钮 |
| 自定义字符 | 字体 Tab 子页 | 本阶段不做（generate 仍自动收集） |
| 清理无用 | 发行说明有 | 「清理未引用」仅清未登记图片文件 |

## 对话框结构

```text
资源管理
├── 图片 | 字体 | 多语言
│   ├── 图片：添加 / 删除 / 清理未引用；列表缩略图+引用数
│   ├── 字体：添加 / 删除；列表+引用数
│   └── 多语言：原 I18nDialog 能力（启用、词条、XLIFF）
└── 关闭
```

## 引用与删除

- 扫描工程 `props` / `style` / `extraData` 字符串中的 `assets/images/…` 与字体 `@id` / `text_font`。
- 引用数 > 0 禁止删除。
- 预览语言下拉可保留在顶栏（快捷），配置入口仅「资源管理 → 多语言」。
