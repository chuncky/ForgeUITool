## 视觉规范（对标 Beken）

Beken 工作区顶栏按钮为 **「图标 + 名称」** 磁贴式控件（纵向：上图标、下文案），而非纯文字 `<button>`。

| 规则 | Beken | 本产品 |
|------|-------|--------|
| 默认按钮 | 内置 SVG/FontAwesome 图标 + 中文标签 | **内联 SVG sprite**（`ToolbarIcon.vue`），禁止依赖 Beken 闭源资源 |
| 撤回 / 重做 | **通用弯箭头图标**，无中文文案 | `icon: undo` / `icon: redo`，**iconOnly**；Tooltip 含快捷键 |
| 项目名称 | 工程名 + 可打开路径（release: 打开项目路径按钮） | 文件夹图标 + 工程名 + `*`；点击打开根目录（FR-010e） |
| 下拉类 | 「C语言 ▾」等保留 ▾ | 同左；下拉面板内仍为文字项 |
| 激活态 | 控件库等 Toggle 有高亮底 | `.tb-btn.on` 边框/底色高亮（FR-010a） |
| 禁用态 | 灰显 + 不可点 | `opacity` + `cursor: not-allowed` |

## Undo / Redo 图标（通用符号）

对标 Beken 与主流 IDE，采用 **左弯箭头 / 右弯箭头**，不使用中文「撤回」「重做」作为主视觉：

```
undo:  ↶  （counter-clockwise arrow，SVG path 见详设 §9.6.0）
redo:  ↷  （clockwise arrow）
```

- 尺寸：20×20 px（`viewBox="0 0 24 24"` 缩放）
- 禁用：`canUndo` / `canRedo` 为 false 时按钮与图标同步灰显
- Tooltip：`撤回 (Ctrl+Z)` / `重做 (Ctrl+Y)`
