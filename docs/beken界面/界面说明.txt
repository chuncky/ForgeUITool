1、启动显示主页界面  对应图片：主界面/主1.png
1.1 启动界面顶部共有五个按钮分别是：主页、工作区、设置、文档、关于。
1.1.1 点击主页按钮显示：主界面/主1.png
1.1.2 点击工作区按钮：没有打开项目时显示新建项目；主界面/主2-新建项目.png，有项目打开时显示工作区界面：主界面/主2-工作区.png
1.1.3 点击设置按钮，显示设置界面   主界面/主3-设置.png
1.1.4 点击文档按钮，显示文档界面   主界面/主4-文档.png
1.1.5 点击关于按钮，显示关于界面   主界面/主5-关于.png

1.2 启动界面主页界面显示分为上、中、下三部分
1.2.1 上部显示：欢迎及介绍
1.2.2 中部显示：快速开始共四个按钮新建项目、导入项目、文档、云资源
1.2.3 下部显示：最近项目


2、工作区界面： 工作区/工作区-全.png
工作区上部依次显示：项目名称、项目设置、组件库、颜色库、资源管理、撤回、重做、存档、历史、代码编辑器、AI设计、C语言、**交付**、MicroPython

**顶栏按钮视觉（对标 工作区/工作区-全.png）：** 除撤回/重做外，均为 **图标 + 名称**（纵向排列：上图标、下文案）；撤回/重做 **仅显示通用弯箭头图标**（无中文），Tooltip 提示快捷键。详见 `工作区顶栏-本产品映射.md`。

2.1 项目名称：显示打开项目的名称 + 文件夹图标；**点击在系统文件管理器中打开项目根目录**（对标 Beken 打开项目文件夹）
2.2 打开项目设置界面：工作区/工作区2-项目设置.png（图标+「项目设置」）
2.3 组件库： 组件库面板开关（图标+「控件库」）
2.4 打开颜色库界面：工作区/工作区4-颜色库.png
2.5 打开资源管理界面：工作区/工作区5-资源管理.png
2.6 撤回按钮：**仅 undo 弯箭头图标**（Ctrl+Z）
2.7 重做按钮：**仅 redo 弯箭头图标**（Ctrl+Y）
2.8 存档按钮，保存项目
2.9 打开历史界面：工作区/工作区9-历史版本.png
2.10 打开代码编辑器界面：工作区/工作区10-代码编辑器.png；**全屏覆盖工作区**（保留顶栏五键与底栏状态行），左侧文件树 + 右侧编辑区。
2.11 打开AI设计界面：工作区/工作区11-AI设计.png
2.12 打开C语言菜单：工作区/工作区12-C语言.png，有全部清理、生成代码、编译、运行、生成代码+编译+运行五个菜单（**仅 A1 静态 C 与 PC 仿真**，不含 SDK 导出 / UI 包）
2.13 打开MicroPython菜单：工作区/工作区13-MicroPython.png，三个菜单：生成代码、运行、生成代码+运行
2.15 打开**交付**菜单（本产品扩展，Beken 无对应项）：**导出到 SDK**（A1 平台接入）、**打包 UI 包**（A2 自有 UI 包，与 C 语言无关）；`deliveryMode=static_c` 时「打包 UI 包」禁用。次要入口：项目设置对话框内同功能按钮。

2.14 工作区布局（对标 工作区/工作区-全.png）
2.14.1 启动后主窗口默认最大化（占满屏幕工作区），非固定小窗。
2.14.2 画布位于工作区中部；其**正下方**固定「构建/运行日志」面板（非全屏遮罩弹层）。
2.14.3 生成/编译/预览时 cmake 输出实时写入该面板；**收起/展开仅位于日志面板标题栏**（非底栏重复按钮），默认展开。
2.14.4 应用壳层**最底行**状态栏显示当前阶段与摘要（如编译进度、总耗时）及平台/LVGL 版本；**不含**日志收起控件。
2.14.5 左栏 **页面与组件树**（对标 `组件面板/页面组件库.png`；本产品现组件 Outline 待改为 PageTreePanel）：
  - **上：页面 [N]** — + 新建；列表切换当前页；**双击页名重命名**；火箭设为启动页；⋯ 重命名/复制/删除/调整顺序（叠层）。
  - **下：控件树 [N]** — 仅显示当前页控件层级；行内眼睛显隐、⋯ 操作菜单（**悬浮于面板之上**，`FloatingPanelMenu` + Teleport）。
  - 详见 `组件面板/页面组件树-本产品映射.md`。
  - 控件库在其上方；顶栏「控件库」仅折叠控件库，不隐藏本面板。
