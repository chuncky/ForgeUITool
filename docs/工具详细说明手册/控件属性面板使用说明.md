## 1. 概述

**属性面板**与**事件面板**共用工作区右栏，通过顶栏 **「属性 | 事件」** Tab 切换（对标 Beken）；同一时刻只显示其一。与左侧**控件库**分工明确：

| 区域 | 职责 | 不得承担 |
|------|------|----------|
| 控件库（左栏） | 从注册表**选型并添加**新控件 | 编辑已选控件字段 |
| 属性 Tab（`PropPanel`） | 编辑选中节点的 `frame` / `props` / `style` | 切换控件库显隐 |
| 事件 Tab（`EventPanel`） | 编辑 `events[]` | 样式 Part/State 编辑（V1 前可只读提示） |

在画布或**页面组件树**中单击控件后，右侧属性区即时同步；修改经 `project:updateNode` 写回 `screens/*.json`，并标记工程为脏（`*`），需**存档**后落盘。

## 2. 面板布局

### 2.1 在工作区中的位置

```
┌──────────┬─────────────────────────────┬──────────────┐
│ 控件库   │         画布                │ 属性 | 事件  │
│ 页面树   │                             │  ─────────   │
│          │                             │  位置信息    │
│          │                             │  属性        │
│          │         日志面板            │  行为配置    │
│          │                             │  样式        │
│          │                             │              │
└──────────┴─────────────────────────────┴──────────────┘
         （「事件」Tab 选中时，上方面板区替换为事件列表）
```

- **默认宽度：** 300px（详设 §9.5）。
- **Tab 切换（对标 Beken）：** 右栏顶栏为 **「属性 | 事件」** 两个 Tab，点击切换；当前 Tab 高亮（底部 accent 色下划线）。切换状态保存在 `uiStore.rightTab`（`props` / `events`）。
- **实现：** `InspectorPanel.vue` 承载 Tab 栏；其下按 Tab 显示 `PropPanel` 或 `EventPanel`（`DesignerWorkbench.vue` 右栏挂载 `InspectorPanel`）。

### 2.2 面板头部

| 元素 | Beken | ForgeUI |
|------|-------|---------|
| 属性 / 事件 Tab | 顶栏点击切换 | ✓ 同结构 Tab |
| 控件类型徽标 | 图标 + 中文类型名（如「按钮」） | 只读 `type` + 中文标签（来自 WidgetRegistry） |
| 控件 ID | `ID: Page_1_button_1` | 只读 `id`（工程内稳定，用于 CodeGen 符号） |
| 显示名 | 大纲/树中的 `name` | 可编辑 `name`（不影响 C 符号） |

> 控件类型、ID、显示名位于 **属性 Tab** 内容区顶部；**事件 Tab** 无此头部，直接展示事件列表。

### 2.3 分组结构（属性 Tab 滚动区）

**属性 Tab** 内（`PropPanel`）按 **折叠分组** 纵向排列，顺序固定：

| 序号 | 分组名 | 说明 | 分期 |
|------|--------|------|------|
| 1 | **位置信息** | 锚点、X/Y、宽/高、旋转、布局类型 | MVP：X/Y/W/H；V1：锚点/旋转/布局 |
| 2 | **属性** | 控件类型专用字段（文本、图片路径等） | MVP：按注册表动态表单 |
| 3 | **行为配置** | 对象标志、对象状态 | V1 |
| 4 | **样式** | Part × State × 样式子组 | MVP：main/default 常用项；V1：完整 Part/State |

各分组标题左侧为蓝色圆点，与 Beken 视觉一致；样式子组右侧 **显示 / 隐藏**：显示时展开编辑区并参与渲染，隐藏时收起且不参与渲染（`disabledSubgroups`，对标 BK `enabledGroups`）。

## 3. 通用操作

### 3.1 选中控件

1. 在**画布**上单击控件，或  
2. 在左侧**控件树**中单击节点。  

未选中时属性区显示「未选中控件」；在**页面树**选中 **screen** 根节点（如 `Page_1`）时，属性首组为 **「屏幕信息」**（宽/高，无 3×3 锚点格），可编辑页面级几何与背景，**不可删除**页面。

**页面属性 Beken 截图：**

![页面-1](../beken界面/属性面板/页面属性/页面属性-1.png)

### 3.2 修改几何（位置信息）

| 字段 | 含义 | 写入 JSON |
|------|------|-----------|
| X | 相对**父容器**左上角水平偏移（px） | `frame.x` |
| Y | 相对父容器垂直偏移（px） | `frame.y` |
| 宽 | 控件宽度（px） | `frame.w` |
| 高 | 控件高度（px） | `frame.h` |

- 亦可在画布上**拖拽移动**；选中后出现 **8 个纯色缩放点**（四角 + 四边中点）及**顶部旋转锚点**（竖线 + 带旋转箭头的圆柄，对标 Beken；手柄在控件外壳层，不被文本裁剪挡住）；左边/上边缩放会同步改 X/Y；旋转绕控件中心，与属性面板「旋转 (°)」同步。  
- 画布拖拽松手后写入历史栈，可用 **Ctrl+Z** 撤回。  
- **3×3 方位格**：点击将控件对齐到**父容器**对应角/边/心（模块详设 §3.5）；九格指示图形必须分方位，禁止九点同图。

**Beken 参照图（位置信息区）：**

- 按钮：![按钮-位置](../beken界面/属性面板/按钮属性/按钮属性-1.png)  
- 标签：![标签-位置](../beken界面/属性面板/标签属性/标签属性-1.png)  
- 图片：![图片-位置](../beken界面/属性面板/图片属性/图片属性-1.png)

**相关：** 旋转角、布局类型（Flex/Grid）见「位置信息」分组；多选对齐见控件菜单（FR-013b），与 3×3 父容器吸附不同。

### 3.3 修改专用属性

字段由 **WidgetRegistry**（`packages/core/src/widgets.ts`）驱动：仅显示当前 `type` 支持的 `props`，变更写入 `node.props`。

### 3.4 修改样式

MVP 编辑 `style.main.default` 下常用键；V1 通过 **PART** / **STATE** 下拉切换后编辑对应子组。

样式面板右上角 **保存 / 样式库** 对标 Beken（FR-018）：保存打开「保存样式」对话框（名称/描述/预览）；样式库打开列表（缩略图、应用、删除）。落盘为 `project.themes[]`，节点可挂 `styleRef`。

### 3.5 删除控件

- 属性面板底部 **「删除控件」**（非 screen），或  
- 控件树 **⋯ → 删除**。  

删除前无二次确认（V1 可加）；操作可撤回。

### 3.6 存档与预览

属性修改仅更新内存与脏标记；**生成代码 / 编译 / 模拟运行** 前会自动存档（若已改动）。手动存档：**Ctrl+S** 或顶栏「存档」。

## 4. 分组字段详述

### 4.1 位置信息（控件）

选中**控件**时，属性首组为 **「位置信息」**，左侧有 **3×3 容器方位格**（对标 Beken）。

| 字段 | Beken | ForgeUI | 说明 |
|------|-------|---------|------|
| 3×3 方位格 | ✓ | ✓ | **示意点在格内对应角/边/心**；点击将控件**吸附到父容器**该方位（见模块详设 §3.5） |
| X / Y | ✓ | ✓ | 相对父容器左上角，整数 px |
| 宽 / 高 | ✓ | ✓ | 最小约 16px（画布约束） |
| 旋转角 | ✓ | ✓ | `frame.rotation` |
| 布局类型 | No Layout 等 | ✓（容器） | Flex/Grid 等 |

**3×3 点击规则（锁定）：**

1. 参考系 = **直接父容器**（页面子控件 → 屏幕；嵌套子控件 → 父控件 `w×h`）。  
2. 左上 / 上中 / 右上 / … / 右下共九种，计算见《控件属性面板详细设计说明》§3.5.1。  
3. **不是**改锚点枢轴、画面不动；**不是**相对随意空白位移。  

**问题对照图：** 错误示意（九点全居中）见 `docs/工具问题/控件属性位置问题/控件属性位置信息的图示九个点.png`。

#### 4.4.1 Part 与 State 选择器

| 控件 | PART（部件） | STATE（状态） |
|------|--------------|---------------|
| 按钮 / 标签 / 图片 / 容器 | MAIN | default、pressed、focused、disabled、checked… |
| 滑块 / 开关 | MAIN、INDICATOR、KNOB | 同上 |
| 进度条 / 加载动画 | MAIN、INDICATOR | 同上 |
| 圆弧 | MAIN、INDICATOR、KNOB | 同上 |
| 下拉菜单 | MAIN、MAIN_LIST、SELECTED_LIST | 同上 |
| 滚轮 | MAIN、SELECTED | 同上 |
| 列表 | MAIN、MAIN_BUTTON、MAIN_ITEM、SCROLLBAR | 同上 |
| 表格 | MAIN、ITEMS | 同上 |
| 标签视图 | MAIN、MAIN_TABBAR、MAIN_TABBARITEM | 同上 |
| 窗口 | MAIN、HEADER、CONTENT、BUTTON | 同上 |
| 消息框 | MAIN、HEADER、CONTENT、FOOTER… | 同上 |
| 文本域 | MAIN、SCROLLBAR | 同上 |
| 图表 | MAIN、（ITEMS / SERIES） | 同上 |

- 右侧样式子组 **显示 / 隐藏**：展开编辑并参与渲染 / 收起且不参与（见 §4.4.2）。

#### 5.0.1 分析方法（对标 Beken AI 接入文档）

1. **权威来源：** `ref/beken/lvgl_ui_designer_2.0.3/resources/ai-skill/beken-lvgl-ui-designer/component-specs/` 中各 `{type}/{type}.md`；运行时以 MCP `get_component_type_spec` 为准（见 `component-specs/README.md`）。
2. **面板分组映射：**
   - **位置信息** ← `layout` 类属性：`x`、`y`、`width`、`height`（及 V1 锚点/旋转/布局）。
   - **属性** ← `general` 类组件字段（如 `text`、`value`、`range`）。
   - **行为配置** ← `behavior` 类：`flags`（对象标志）、`state`（预览状态）。
   - **样式** ← `style.parts[]`：按 **PART × STATE** 编辑 `background` / `font` / `border` 等子组。
   - **扩展数据** ← `extraData`：列表项、Span 段、图表 series、菜单 pages 等；Beken 在 **属性** 分组内提供列表/表格编辑器，**非**子控件树。
3. **属性 vs 样式：** 组件值走 `properties`（ForgeUI `props`）；视觉走 `style`（ForgeUI `style`）。`Common/Range` 在 Beken 为 `{min,max}` 对象，勿写逗号字符串（见 AI `style-guidelines.md`）。
4. **ForgeUI 分期：** 表内「ForgeUI」列：`props.*` 表示 MVP 已支持或计划同名；`V1` 表示待注册表与 UI 补齐。

#### 5.0.2 多 Part 控件速查

| 控件 | PART | 典型用途 |
|------|------|----------|
| 滑块 / 进度条 / 开关 | main、indicator、knob | 轨道、填充、拖柄 |
| 下拉菜单 | main、main_list、selected_list | 收起框、列表、选中行 |
| 列表 | main、main_button、main_item | 容器、按钮行、文本行 |
| 表格 | main、items | 外框、单元格 |
| 标签视图 | main、main_tabbar、main_tabbaritem | 内容、标签栏、标签项 |
| 窗口 | main、main_header、main_content、main_button | 外框、标题栏、客户区、按钮 |
| 消息框 | main、main_header、main_content、main_footer… | 对话框各区域 |

## 6. 事件面板（「事件」Tab）

点击右栏顶栏 **「事件」** Tab 进入；选中非 screen 控件时可编辑。与 **「属性」** Tab 互斥显示，内容区占满右栏剩余高度并可滚动。

| 项 | 说明 |
|----|------|
| 触发器 | `CLICKED`、`PRESSED`、`RELEASED`、`LONG_PRESSED`、`VALUE_CHANGED` |
| 动作 MVP | **切页**（`CHANGE_SCREEN`）、**Call function**（`CALL_FUNCTION`） |
| 写回 | `project:setEvents` → `node.events[]` |

按钮、图片常见：`CLICKED` → 切页或调用 C 处理函数。标签通常无事件，面板显示空列表时可 **+ 事件** 添加。

## 9. 常见问题

**Q：改了属性但仿真里没变？**  
A：先 **存档**，再执行「生成代码+编译+模拟运行」。生成流程会自动存档，但仅预览旧产物时仍可能不一致。

**Q：属性面板是灰的 / 无字段？**  
A：确认已打开工程且选中了具体控件（不是空白画布）。screen 根节点字段较少。

**Q：首组是「屏幕信息」还是「位置信息」？**  
A：页面树选中 **Page_x** → **屏幕信息**（无锚点格）；画布/组件树选中控件 → **位置信息**（有 3×3 锚点格）。截图脚本分别用 `--page-only` 与 `--shot-only`。

**Q：找不到图片路径选择？**  
A：MVP 可在 `props.src` 手填相对路径；先在 **资源管理** 导入文件。

**Q：样式 Part/State 与 Beken 不一致？**  
A：V1 前默认编辑 **MAIN + DEFAULT**；按 §4.4.1 表扩展 INDICATOR/KNOB 等于 V1 起支持。

**Q：属性面板和控件库有什么关系？**  
A：顶栏「控件库」**只**显示/隐藏左侧控件库，**不会**隐藏右侧属性/事件检查器（FR-010a）。

**Q：如何编辑控件事件？**  
A：在右栏顶栏点击 **「事件」** Tab，选中非 screen 控件后即可添加/编辑 `events[]`；编辑属性时切回 **「属性」** Tab。
